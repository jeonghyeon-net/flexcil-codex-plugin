# ADR-003: 원본 보존과 재개 가능한 여러 파일 쓰기

상태: 채택. 결정일: 2026-09-28.

## 배경

Flexcil 문서 ZIP, 활성 목록과 휴지통은 별개 Drive 파일입니다. 새 문서나 이름 변경, 휴지통 이동 도중에 연결이 끊기거나 다른 기기가 편집할 수 있습니다. 일반 파일 업로드만으로 여러 파일을 원자적으로 바꾸거나 충돌을 없앨 수는 없습니다.

## 결정

작업별로 원본·후보·해시·대상 식별자·진행 기록을 보관합니다. 게시 전에 최신 원격 바이트를 비교하고 각 게시 후 다시 내려받아 확인합니다. 이미 후보가 적용된 단계는 같은 작업 ID로 재개할 때 건너뜁니다. 새 문서는 Drive ID를 먼저 예약해 재시도의 중복 생성을 줄입니다.

휴지통 이동은 복원 레코드를 먼저 쓰고 활성 참조를 제거합니다. 복원은 활성 참조를 먼저 쓰고 휴지통 레코드를 제거합니다. 중단으로 생긴 중복 참조를 고아 파일 삭제의 근거로 사용하지 않습니다.

알 수 없는 ZIP 항목을 보존하며 원본을 로컬 편집 결과로 덮어쓰지 않습니다. `rollback`은 원격이 여전히 해당 후보일 때 복원 파일만 만듭니다. 후속 편집이 있으면 새로운 계획으로 복구합니다.

## 대안과 결과

무조건 덮어쓰기와 중단 후 전체 재실행은 외부 편집 손실·중복 생성을 유발할 수 있어 채택하지 않았습니다. 여러 파일에 대한 원자적 트랜잭션은 제공하지 않습니다. 최종 비교와 쓰기 사이의 경쟁 조건도 남습니다.

백업과 단계별 기록 덕분에 실패한 작업을 조사할 수 있지만, 오래된 백업의 보관 기간과 삭제는 사용자가 결정해야 합니다. 자동 검증은 Drive 바이트 일치와 기기 표시·새 필기 회수를 별도의 단계로 구분합니다.
