# ADR-001: 스킬·파일 엔진 분리와 표준 PDF 전달

상태: 채택. 결정일: 2026-09-28.

## 배경

PR 리뷰, 회의록, 학습 자료 등 문서의 목적과 레이아웃은 서로 다릅니다. Flexcil 연결이 특정 보고서 양식이나 문제풀이 흐름에 종속되면 다른 스킬의 산출물을 사용하기 어렵습니다.

## 결정

Codex 스킬이 의도 해석과 작업 순서를 맡습니다. 문서 작성은 적합한 문서·PDF·프레젠테이션 스킬이 수행하고, **PDF·제목·가상 폴더 경로**를 Flexcil 플러그인에 전달합니다. 출처 링크는 문서 내용에 포함할 수 있습니다.

파일 엔진은 문서·페이지·객체·도서관을 읽고 변형합니다. 형식 엔진에는 네트워크를 넣지 않고 JSON CLI로 호출합니다. 필기 해석은 렌더 이미지를 읽는 Codex가 담당합니다.

## 대안과 결과

전용 보고서 DSL은 문서 작성 스킬과 역할이 겹쳐 채택하지 않았습니다. 별도 원격 서버나 항상 실행하는 MCP 프로세스 없이 명시적 CLI 호출로 구성했습니다.

PDF를 전달하면 이미 검증한 문서 레이아웃과 원본 첨부를 유지할 수 있습니다. PDF 안의 모든 글자를 Flexcil 네이티브 텍스트 객체로 변환하지는 않습니다. 네이티브 객체 편집과 정밀 렌더링은 파일 엔진의 별도 기능으로 구현해야 합니다.
