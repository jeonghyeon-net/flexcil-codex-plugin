# ADR-002: 사용자별 직접 Google 연결과 앱 전용 등록

상태: 채택. 결정일: 2026-09-28.

## 배경

기존 파일의 바이트 수정과 새 문서 등록에는 다른 조건이 필요합니다. 관측한 Android 동기화 경로는 Google Drive의 앱 전용 속성으로 파일을 열거합니다. 같은 계정의 Drive에 일반 파일을 올렸다는 사실만으로 Flexcil에 새 문서가 표시되지는 않습니다.

## 결정

사용자가 명시적으로 제공한 OAuth 설정으로 새로운 PKCE 로그인을 수행합니다. 사용자가 선택한 APK/XAPK에서는 공개 설정만 읽고 실행하지 않습니다. 클라이언트 설정·토큰·콜백은 각 사용자의 비공개 상태 디렉터리에 둡니다.

Mac에서는 로컬 콜백 수신기를 구성합니다. Google 동의 화면의 앱 표시와 실제 연결을 사용하는 플러그인의 관계를 설명하고 사용자가 직접 동의합니다. `connection-probe`가 앱 전용 속성을 읽는지 확인한 뒤 신규 등록을 허용합니다. 일반 쓰기는 새 테스트 문서의 태블릿 왕복을 통과한 프로필에서 수행합니다.

## 대안과 결과

일반 Codex Drive 커넥터는 기존 파일 전송의 대안으로 유지합니다. 그 연결만으로 앱 전용 속성에 접근한다고 가정하지 않습니다. 수동 PDF 가져오기는 직접 등록이 불가능한 경우의 명시적 대안입니다.

이 경로는 컴퓨터의 Flexcil 앱, 태블릿 디버깅, 태블릿 보조 앱 없이 새 문서의 실제 왕복을 통과했습니다. 앱의 OAuth 정책·파일 형식·동기화 방식에 의존하므로 버전이 바뀌면 다시 검증해야 합니다. 공개 플러그인에 특정 클라이언트 설정을 내장하지 않으며 공식 통합이라고 표시하지 않습니다.
