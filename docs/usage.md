## 설치와 업데이트

릴리스 ZIP 설치는 [README](../README.md)의 순서를 따릅니다. ZIP에는 로컬 marketplace와 플러그인 소스가 함께 들어 있습니다. Python 의존성과 개인 연결 정보는 포함하지 않습니다.

Linux에서는 `sha256sum -c flexcil-codex-plugin-v0.1.0.zip.sha256`으로 검사합니다. Windows PowerShell에서는 `Get-FileHash .\flexcil-codex-plugin-v0.1.0.zip -Algorithm SHA256`의 결과를 `.sha256`의 값과 비교하고 `Expand-Archive`로 압축을 풉니다. 패키지를 받을 수 있다는 사실과 플랫폼별 직접 로그인 지원은 별개입니다. 현재 자동 콜백 수신기는 macOS용입니다.

소스로 설치하려면 다음 명령을 사용합니다.

```sh
git clone https://github.com/jeonghyeon-net/flexcil-codex-plugin.git
cd flexcil-codex-plugin
codex plugin marketplace add .
codex plugin add flexcil-codex-plugin@personal
```

`codex plugin list`에서 이 저장소의 로컬 카탈로그를 가리키는지 확인합니다. 카탈로그 이름 `personal`이 기존 항목과 충돌하면 기존 항목을 덮어쓰지 말고 Codex의 marketplace 관리 기능으로 설치 대상을 먼저 정리합니다. 유지관리자는 Codex 플러그인 생성 도구를 사용해 별도 이름의 카탈로그를 만들 수 있습니다.

업데이트는 새 릴리스의 체크섬을 확인해 기존 소스 디렉터리와 별도로 압축을 푼 뒤 해당 카탈로그를 연결하고 `codex plugin add flexcil-codex-plugin@personal`을 다시 실행합니다. 소스 설치는 작업 중인 변경을 보존한 뒤 `git pull --ff-only`하고 같은 명령으로 갱신합니다. 새 스킬을 사용하려면 새 채팅을 시작합니다. 프로필과 백업은 설치 디렉터리 밖에 있어 업데이트 후에도 유지됩니다.

## 첫 연결

새 채팅에서 **“Flexcil 연결 설정해줘”**라고 요청합니다. 설정은 다음 순서로 진행됩니다.

1. **실행 환경 준비:** Codex의 Python 또는 별도 Python 3.10 이상에서 `doctor`를 실행합니다. 의존성이 없으면 전용 가상환경을 만듭니다.
2. **도서관 선택:** 연결된 Google Drive에서 Flexcil 동기화 폴더를 찾습니다. 후보가 여러 개면 사용할 도서관을 선택합니다. 문서마다 설정하는 방식이 아니라 도서관을 프로필에 연결합니다.
3. **직접 Google 연결:** 사용자가 제공한 OAuth 설정 파일 또는 선택한 APK/XAPK의 공개 설정으로 로그인합니다. APK를 실행하거나 다른 앱에서 토큰을 복사하지 않습니다.
4. **사용자 동의:** 시스템 브라우저의 Google 화면에서 직접 로그인·동의합니다. Google 화면에는 제공된 OAuth 설정의 앱 이름이 표시되고, 새 연결은 이 플러그인이 보관하고 사용합니다. 코드·토큰·콜백 URL을 채팅에 붙여 넣을 필요는 없습니다.
5. **접근 검사:** `connection-probe`로 Flexcil의 앱 전용 속성에 실제로 접근하는지 확인합니다. 일반 Google Drive 연결만으로 신규 등록이 가능하다고 판단하지 않습니다.
6. **테스트 문서:** 전용 PDF 문서를 생성합니다. 태블릿에서 동기화해 문서를 열고 한 줄을 필기한 다음 닫아 동기화합니다. 플러그인이 새 필기와 기존 내용 보존을 확인하면 해당 프로필의 일반 쓰기를 활성화합니다.

이후 문서를 만들 때마다 필기 확인을 요구하지 않습니다. 계정·도서관·플랫폼이 바뀌거나 Flexcil 업데이트로 호환성이 달라지면 별도 테스트를 다시 진행합니다.

## 자주 쓰는 요청

| 요청 | 처리 |
| --- | --- |
| “개발 폴더 아래 문서를 보여줘” | 최신 도서관의 경로·문서·휴지통을 구분해 조회 |
| “이 PR을 문서로 만들어 개발/리뷰에 넣어줘” | PR 읽기 → 문서 스킬의 PDF → 새 문서 등록 → 없는 폴더 생성·배치 |
| “이 PDF를 기존 회의 노트 마지막에 붙여줘” | PDF 페이지를 원본 첨부로 추가하고 기존 필기 보존 |
| “어제 필기한 내용을 읽고 정리해줘” | 원본 텍스트 추출·페이지 미리보기 → Codex의 필기 해석 |
| “이 문서 이름을 바꾸고 보관/완료로 옮겨줘” | 문서와 목록의 제목을 함께 갱신하고 가상 폴더 이동 |
| “이 노트를 휴지통으로 보내줘” | 복원 가능한 휴지통 레코드를 먼저 작성하고 활성 목록 갱신 |
| “휴지통의 이 노트를 개발 폴더로 복원해줘” | 지정한 폴더로 복원. 폴더를 지정하지 않으면 루트 |
| “이 페이지를 필기 포함 PDF로 뽑아줘” | 지원되는 레이어를 래스터 PDF로 내보내고 근사·생략 보고 |

동일한 제목의 문서나 폴더가 있으면 경로·식별자로 대상을 구별합니다. Flexcil 폴더는 `documents.list` 안의 가상 폴더입니다. Google Drive 폴더를 새로 만드는 작업과 다릅니다.

## 다른 스킬과의 협업

문서·PDF·프레젠테이션 스킬은 원하는 레이아웃으로 PDF를 만듭니다. Flexcil 플러그인은 PDF와 제목, 폴더 경로를 받아 기존 노트에 삽입하거나 새 문서를 생성합니다. 전용 보고서 문법을 요구하지 않습니다.

PR의 링크와 출처는 문서 안에 넣을 수 있습니다. PR 분석을 요청했다고 댓글 작성이나 저장소 변경까지 수행하지 않습니다. “끝나면 알려줘”의 결과는 현재 Codex 채팅으로 안내합니다. 나중에 확인하거나 반복 실행하는 요청은 Codex 자동화 기능과 연결합니다.

## 렌더링과 읽기

원본 PDF는 문서의 첨부로 유지합니다. 읽기용 이미지는 PDF 배경과 기본 필기·텍스트를 합성하며 펜 굵기·서체·줄바꿈은 근사치입니다. 이미지·도형·마스킹·링크·회전 등 지원하지 않는 레이어는 원본에 보존하고 미리보기의 생략 항목으로 보고합니다.

`render`와 `export-pdf`의 `--strict`는 근사 또는 생략이 있으면 출력을 거절합니다. 필기 포함 내보내기는 래스터 PDF이며, 편집 가능한 벡터 PDF 변환은 제공하지 않습니다. 필기 인식은 렌더 이미지를 읽는 Codex가 담당합니다.

미리보기 글꼴은 `FLEXCIL_FONT` 또는 `--font`로 Unicode TTF/TTC 파일을 지정할 수 있습니다. 원본 노트의 서체 설정은 바뀌지 않습니다.

## 동기화 결과와 재시도

| 결과 | 의미 |
| --- | --- |
| `prepared` | 원본·후보·작업 기록 생성. 게시 전 상태 |
| `document_verified` | 새 문서 파일과 앱 전용 등록 확인. 목록 게시가 남을 수 있음 |
| `cloud_verified` | 관련 Drive 파일을 재다운로드해 후보와 일치함을 확인 |
| `device_verified` | 첫 연결 시험에서 태블릿 표시 확인과 새 필기 회수까지 완료 |

`cloud_verified`만으로 현재 태블릿 화면이 갱신됐다고 말하지 않습니다. 태블릿의 Flexcil에서 동기화를 마친 뒤 확인합니다.

네트워크가 끊겼다면 작업 ID를 유지해 재시도합니다. 새 문서는 `publish-document`, 기존 문서·도서관 변경은 `publish-update`가 완료된 단계를 확인하고 이어갑니다. 외부 편집을 감지하면 해당 작업과 현재 파일을 보존하고 새 계획을 만듭니다. 백업을 강제로 덮어쓰지 않습니다.

## 문제 해결

| 증상·오류 | 확인할 내용 |
| --- | --- |
| 설치했는데 스킬이 보이지 않음 | 새 채팅을 시작하고 `codex plugin list`에서 설치 경로 확인 |
| `doctor`에서 의존성 누락 | 설정 스킬로 별도 실행 환경 준비 |
| 검색 결과가 비어 있음 | 일반 검색에서 커스텀 MIME이 빠질 수 있으므로 동기화 폴더 자식 또는 직접 연결의 전체 목록 조회 |
| `sync_probe_required` | 해당 프로필에서 새 테스트 문서의 태블릿 왕복 완료 |
| `wrong_oauth_context` | 연결이 Flexcil 앱 전용 속성을 볼 수 없음. 제공한 OAuth 설정과 계정 확인 |
| `callback_runtime_missing` | Mac의 Swift 명령행 도구와 콜백 수신기 준비 상태 확인 |
| `callback_handler_exists` | 같은 콜백을 사용하는 앱이 이미 있음. 기존 등록을 강제로 교체하지 말고 연결 방식 확인 |
| `expired_login` / `login_required` | 새 로그인 시작. 인증 URL이나 토큰을 이슈에 첨부하지 않음 |
| `stale_source` / `candidate_changed` | 준비 후 원격 또는 후보가 변경됨. 원본·후보를 보존하고 최신 자료로 재계획 |
| `ambiguous_name` | 중복 제목을 경로·식별자로 구분 |
| 문서가 아직 태블릿에 없음 | 작업의 마지막 검증 단계, 앱 동기화, 같은 도서관 사용 여부 확인 |

자세한 명령과 JSON 편집 계획은 [CLI 명세](../plugins/flexcil-codex-plugin/skills/flexcil/references/commands.md), 전송 순서는 [Drive 연결 명세](../plugins/flexcil-codex-plugin/skills/flexcil/references/drive.md)를 참고합니다. 오류를 제보할 때는 [기여 안내](../CONTRIBUTING.md)에 따라 개인 정보를 제거합니다.
