# 지원 범위와 완성 기준

2026-09-28 기준. 명령의 현재 목록은 CLI `capabilities`, 시험 근거는 [검증 기록](verification.md)에 있습니다. 이 문서는 전체 Flexcil 기능 구현을 목표로 남은 범위를 추적합니다. 버전 번호나 릴리스 게시를 전체 기능 완료의 근거로 삼지 않습니다.

## 검증 수준

- **태블릿 왕복:** 사용자가 실제 표시를 확인하고 새 필기를 추가한 파일을 다시 회수했습니다.
- **Drive 재검증:** 실제 업로드와 재다운로드를 확인했습니다. 모든 중간 태블릿 화면을 확인했다는 뜻은 아닙니다.
- **로컬 검사:** 합성 자료 또는 비공개 샘플로 엔진 동작을 검사했습니다. 실기기 호환성을 대신하지 않습니다.

## 플랫폼과 동기화 조건

| 환경 | 현재 상태 |
| --- | --- |
| macOS + Android Flexcil + Google Drive | 직접 로그인, 새 문서, 기존 노트 텍스트, 필기 회수 확인 |
| Windows/Linux 컴퓨터 | 파일 엔진의 이식성을 고려했으나 자동 OAuth 콜백·실환경 실행 미검증 |
| iOS Flexcil | 실제 쓰기 미검증 |
| Google Drive 이외의 동기화 서비스 | 미구현 |
| 문서 포맷 0.0.4 / 0.0.5 | 관측 샘플 읽기·로컬 편집 검사. 다른 버전은 쓰기 거절 |

신규 등록에는 Flexcil의 앱 전용 속성을 볼 수 있는 직접 연결이 필요합니다. 각 사용자 프로필에서 `connection-probe`와 새 문서 시험을 통과해야 합니다. 직접 연결이 없으면 수동 PDF 가져오기를 명시적 대안으로 제공합니다.

최신 바이트 비교는 구현했지만 최종 다운로드와 업로드 사이에 경쟁 조건이 남아 있습니다. 여러 Drive 파일을 원자적으로 갱신하지 않습니다. 쓰는 동안 같은 문서를 다른 기기에서 편집하지 않는 것이 현재 운영 조건입니다.

## 전체 기능 완성까지 남은 작업

아래 항목은 아직 충족하지 못한 완료 조건입니다. 새 기능은 명령 구현, 데이터 보존 시험, 필요한 기기 검증, 스킬·사용 안내까지 함께 완료합니다.

- [ ] 전체 문서 복제와 모든 내부 참조·식별자 재구성
- [ ] 네이티브 노트·표지·템플릿·플래너 생성과 편집
- [ ] 모든 객체 유형의 생성·읽기·변경·삭제와 참조 일관성
- [ ] 변형·이미지·도형·마스킹·링크를 포함한 렌더링 검증
- [ ] 즐겨찾기·책갈피·태그 관리
- [ ] 영구 삭제 시 참조·첨부·동기화 메타데이터 정리와 복구 정책
- [ ] 공유·녹음·앱 설정 등 남은 기능의 경로 조사와 구현
- [ ] 지원 플랫폼별 로그인·기기 왕복·중단 복구 시험
- [ ] 실제 태블릿에서 페이지 편집·이름 변경·휴지통·복원의 단계별 확인
- [ ] 동시 변경 처리 보강과 대규모 도서관·장시간 동기화 검증

세부 파일 형식과 생성 경로는 [포맷 조사](format-and-sync.md), [Android 생성 분석](android-document-creation.md)에 기록합니다.
